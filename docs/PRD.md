> **版本 V7.0** · 2026-06-23  
> **定位**：单用户、本机运行、长期开源 MVP · **双模式：个人投顾 + 专业投研**  
> **仓库**：[github.com/Miles128/StockResearch](https://github.com/Miles128/StockResearch)

## 一、产品定义

### 1.1 一句话

**双模式 AI 投资助手**：个人投顾模式帮你看懂"今天该关注什么"，专业投研模式给你四维深度分析。打开 5 分钟，知道与你有关的事情发生了什么变化。

一个产品，两种视角，同一份数据。

### 1.2 与市面产品的区别

作为 MVP 项目，不声称超越市面产品，只在几个点上做差异化尝试：

| 产品 | 我们尝试不同的地方 |
|------|------|
| 同花顺 / 东方财富 | 信息洪流之外，试试"少即是多"；既有投研也有投顾视角 |
| 雪球 | 不做社交，只围绕你自己的持仓 |
| AI 聊天 | 把持仓上下文带进对话，回答尽量有结论 |
| 银行 AI 投顾 | 不推产品，只解释；考虑你的现金流和风险承受能力 |

**双模式**是核心差异化尝试：投顾模式考虑个人现金流和风险承受能力、用大白话；投研模式专注深度分析、术语直出。

### 1.3 为谁做

| 用户 | 特征 | 默认模式 |
|------|------|----------|
| **主用户 A** | A 股个人投资者，持仓 3–15 只，不缺信息缺"该看哪个" | 个人投顾 |
| **主用户 B** | 专业投资者/分析师，需要四维深度+多空辩论+完整指标 | 专业投研 |
| **次要用户** | 会折腾 AkShare / Tushare / 本地大模型的开源使用者 | 专业投研 |

**关键设计**：同一个用户在不同场景下会切换模式。盘前看投顾（今天该关注什么），深入研究某只股时切投研（四维分析）。模式不是用户身份的固化，而是当前任务的视角。

### 1.4 三点哲学（不变）

1. **帮用户理解**，不是帮用户决策
2. **帮用户发现变化**，不是发现机会
3. **帮用户管理风险**，不是提高收益

这三条天然合规。**双模式不改变这三条**——投顾模式是"主动告诉你该理解什么"，投研模式是"深度帮你理解"，都不是帮你决策。

### 1.5 核心设计原则

> 行为金融学的基本发现：信息量超过阈值后，散户决策质量反而下降。  
> 损失厌恶使负面信号的权重是正面信号的 2 倍。

**原则 1：少即是多。** 首屏不超过 5 条可行动信号。每增加一条，边际价值为负。投顾模式严格执行；投研模式放开（专业人需要完整数据）。

**原则 2：负面信号如实呈现 + 免责声明。** 确切负面的信号如实展示，不强行配平。不为了"舒服"而淡化真实风险。每条风险告警附带免责声明："以上内容由 AI 生成，仅供参考，不构成投资建议。"

**原则 3：先给确定性，再给数据。** 先说 🟢 安全，再说 VaR = 4.32%。

**原则 4：舒服 > 震撼。** 不说"紧急止损"，说"触及关注线"。不用红色大字。但原则 4 不凌驾于原则 2——真实风险不为了舒服而粉饰。

**原则 5：文字让普通人和专业人士都能看懂。** 这是贯穿所有模块的硬性写作标准——不是风格偏好，是能力要求。**投顾模式用非金融术语的大白话解释，投研模式术语直出，两者各自达标。**

**原则 6：双模式，同一份数据。** ★（V7.0 新增）  
投顾和投研不是两个产品，是同一份数据的两种呈现。后端数据层、Agent 推理层完全共享，只有**呈现层和写作风格**按模式切换。这保证：① 投顾模式不会因为简化而丢失准确性；② 投研模式不会因为专业而失去持仓上下文。

### 1.6 四个 Wow 时刻（设计目标）

| # | 瞬间 | 用户看到的是 |
|---|------|-------------|
| Wow #1 | 它知道什么对我重要 | `央行降准 → 因为你持有招商银行（仓位 30%，属银行板块）` |
| Wow #2 | 它把看不懂的翻译成人话 | 风控页第一行是 ¥2,300，不是 VaR = 4.32% |
| Wow #3 | 它帮我看到我看不到的东西 | K 线上自动出现支撑线，AI 两句话说清现在的处境 |
| Wow #4 | ★ 一键切换视角 | 投顾模式看"今天该关注什么"，切到投研立刻是四维深度+多空辩论，同一只股 |

### 1.7 体验弧线（从打开到离不开）

```
第 0-1 分钟 → 首次引导：选"我是新手/我是专业投资者"，自动设模式 + 示例持仓已加载
第 1-3 分钟 → 投顾模式：Daily Briefing 已在运转，看到"今天该关注的 3 件事"（Wow #1）
第 3-5 分钟 → 录入真实持仓，首次看到关联逻辑
第 5-10 分钟 → 切到投研模式：点进 F6，K 线 + 辅助线 + 四维分析 + 多空辩论（Wow #3/#4）
           → 风控页 ¥2,300 而非 VaR（Wow #2）
第一周      → 盘前用投顾看 Briefing，深入研究时切投研，不再打开同花顺
```

## 二、Relevance Engine（系统判断力的来源）

> 系统怎么知道"什么与你有关"？—— 三层规则为主，轻量 LLM 兜底。

### 2.1 三层规则

| 层 | 内容 | 实现 |
|----|------|------|
| 股票 → 板块映射 | 招商银行→银行，贵州茅台→白酒 | 静态表，持仓录入时打标签 |
| 新闻 → 板块映射 | "降准"→银行/券商/地产 | `sector_keywords.json` 关键词表 |
| 相关性评分 | `Score = Importance × Exposure` | 规则计算，无 LLM |

示例：降准 Importance=90 × 招商银行 Exposure=0.30 = 27 分，排在消费数据 80×0.05=4 分前面。符合用户直觉。

### 2.2 轻量 LLM 补丁

只处理规则层漏网的两类情况：
- 公司特定新闻（"招商银行被监管调查"——不匹配任何板块关键词）
- 负面量级判断（降 0.25bp vs 降 1bp，重要性完全不同）

LLM 只返回结构化输出 `{"target": "...", "sentiment": -1, "magnitude":"high"}`，不做完整分析。

### 2.3 显式呈现关联逻辑（关键设计决策）

推送时必须暴露连接逻辑。这是和同花顺推送的根本区别，也是建立用户信任的核心。

```
❌ 央行降准政策出现
✅ 央行降准 0.5 个基点 → 因为你持有招商银行（仓位 30%，属银行板块）
```

### 2.4 紧迫性 ≠ 相关性

两个维度分开处理：

| | 高相关性 | 低相关性 |
|---|----------|----------|
| **高紧迫** | 止损触发 → 立刻展示 | 大盘暴跌但不持相关股票 → 低调展示 |
| **低紧迫** | 降准影响银行持仓 → 今日内展示 | 不持相关股票 → 不推送 |

### 2.5 两个容易被忽视的信号

- **趋势信号**：仓位 45% + 近 5 天快速恶化 ≠ 仓位 45% + 稳定一个月。加"变化速度"维度
- **静默信号**：持仓股突然停止产生新闻，可能预示重大事件前静默期

## 三、系统架构

```
┌─────────────────────────────────────────────────────┐
│  模式层（V7.0 新增）                                  │
│  个人投顾 ←→ 专业投研  ·  顶栏一键切换 · 持久化       │
├─────────────────────────────────────────────────────┤
│  呈现层（前端，按模式差异化）                          │
│  默认页 · 信息密度 · 写作风格 · 术语弹窗 · 辩论开关     │
├─────────────────────────────────────────────────────┤
│  推理层（后端，模式无关，全共享）                       │
│  LangGraph Orchestrator · 四维 ReAct · 多空辩论 · 风控 │
├─────────────────────────────────────────────────────┤
│  数据层（后端，模式无关，全共享）                       │
│  行情 · 新闻 · 财报 · 板块 · 持仓                      │
└─────────────────────────────────────────────────────┘

浏览器 (localhost:5174)  ──REST/SSE──▶  FastAPI (127.0.0.1:8000)
                                              │
                                         SQLite (stockresearch.db)
                                              │
                                    LangGraph 多 Agent + 行情/新闻
```

| 层 | 技术 | 模式相关性 |
|----|------|-----------|
| 前端 | React 18, TypeScript, Vite | **按模式切换呈现** |
| 后端 | FastAPI, SQLAlchemy | 模式无关 |
| Agent | LangGraph, 自研 ReAct | 模式无关（reading_mode 参数控制写作） |
| 存储 | SQLite 单文件 | 模式无关 |
| 行情 | 新浪 → AkShare 降级 | 模式无关 |
| LLM | OpenAI 兼容 API（BYOK） | 模式无关 |

**关键**：模式切换只影响前端呈现和 LLM 写作风格（通过 `reading_mode` 参数），后端 Agent 推理和数据完全共享。这保证投顾模式不会变笨，投研模式不会失去持仓上下文。

## 四、双模式架构 ★（V7.0 核心）

### 4.1 模式定义

**两个核心差异**（其他差异都派生自这两点）：

1. **是否考虑个人现金流和风险承受能力**：投顾模式考虑，投研模式不考虑
2. **语言表现**：投顾模式用非金融术语的大白话，投研模式术语直出

| 维度 | 个人投顾（advisor） | 专业投研（research） |
|------|---------------------|---------------------|
| **★ 核心差异 1** | **考虑个人现金流和风险承受能力** | **不考虑，纯分析** |
| **★ 核心差异 2** | **大白话解释，避免金融术语** | **术语直出，专业口径** |
| 定位 | 帮你看懂"今天该关注什么" | 给你四维深度分析 |
| 默认首页 | Action Center（今日决策清单） | Chat（自由提问） |
| 信息密度 | 少即是多，首屏 ≤ 5 条 | 完整数据，不限条数 |
| 视角 | 组合优先（你的持仓整体） | 个股优先（深度分析） |
| 主动性 | 主动推送建议（关注什么） | 被动响应提问 |
| 多空辩论 | 默认关（新手不需要分歧） | 默认开（专业人要看分歧） |
| 术语弹窗 | 默认开（PE/ROE 可点击解释） | 默认关（术语直出） |

**核心差异 1 的具体表现**：
- 投顾模式：风险告警结合用户风险承受能力分级（保守/稳健/进取），结合现金流影响（"这次下跌会让你浮亏 ¥2,300，相当于你月收入的 15%"）
- 投研模式：只给 VaR、回撤等指标，不结合个人财务状况

**核心差异 2 的具体表现**：
- 投顾模式：`friendly` 写作——"赚钱能力很强，每 100 元本金一年能赚 32 元"
- 投研模式：`professional` 写作——"ROE 32.1%（行业均值 18.2%），毛利率 52.3%"

### 4.2 模式差异矩阵（前端派生配置）

```typescript
// modeSettings.ts
type AppMode = "advisor" | "research";

interface ModePreset {
  mode: AppMode;
  defaultTab: Tab;           // advisor → "chat" / research → "chat"
  readingMode: ReadingMode;  // advisor → friendly / research → professional
  enableDebate: boolean;      // advisor → false / research → true
  enableGlossary: boolean;     // advisor → true / research → false
  maxSignals: number;          // advisor → 5 / research → 20
}
```

### 4.3 模式切换

**入口**：顶栏常驻切换器，与中/EN 语言切换同级。

```
┌──────────────────────────────────────────────────────┐
│ StockResearch   [个人投顾] [专业投研]   中/EN  ⚙️    │
├──────────────────────────────────────────────────────┤
│  [F1对话] [F2新闻] [F3持仓] [F4风控] [F5设置]       │
└──────────────────────────────────────────────────────┘
```

**切换行为**：
1. 一键切换，立即生效（无需刷新）
2. 同步更新 6 个派生配置（defaultTab / readingMode / enableDebate / enableGlossary / maxSignals）
3. 持久化到 localStorage，下次打开记住选择
4. 后端通过现有 `reading_mode` + `enable_debate` 参数接收，**后端零改动**

**为什么放顶栏而不是 TabNav**：
- TabNav 是功能页（去哪），模式切换是视角切换（怎么看），语义不同
- 顶栏常驻，切换后所有页面联动
- 和语言切换同级，都是全局视角

### 4.4 模式内微调

模式是预设包，但用户可在 Settings 内微调单项：

| 微调项 | 投顾默认 | 投研默认 | 可微调范围 |
|--------|---------|---------|-----------|
| 写作风格 | friendly（大白话） | professional（术语） | friendly / professional |
| 多空辩论 | 关 | 开 | 开 / 关 |
| 术语弹窗 | 开 | 关 | 开 / 关 |
| 首屏信号数 | 5 | 20 | 3 / 5 / 10 / 20 |
| 风险承受能力分级 | 必填（保守/稳健/进取） | 不启用 | 保守 / 稳健 / 进取 |
| 现金流上下文 | 启用（结合月收入换算） | 不启用 | 启用 / 不启用 |

**规则**：微调不改变当前模式标签，只改单项配置。用户在投顾模式下手动开辩论，模式仍是"个人投顾"，但辩论已启用。Settings 面板显示"当前模式：个人投顾（已自定义）"。

**投顾模式专属**：风险承受能力分级和现金流上下文是投顾模式的核心，首次引导时必填。投研模式不启用这两项，纯分析不结合个人财务状况。

### 4.5 首次引导（Onboarding）

首次访问触发，按所选模式走不同流程：

**Step 1：选模式**
```
┌──────────────────────────────────────┐
│  欢迎使用 StockResearch              │
│                                       │
│  你更接近哪种？                       │
│                                       │
│  ┌─────────────┐  ┌─────────────┐    │
│  │  个人投顾    │  │  专业投研    │    │
│  │              │  │              │    │
│  │ 考虑你的     │  │ 四维深度     │    │
│  │ 现金流和风险  │  │ 多空辩论     │    │
│  │ 承受能力     │  │ 完整指标     │    │
│  │ 大白话解释    │  │ 术语直出     │    │
│  │              │  │              │    │
│  │ 适合新手      │  │ 适合专业人   │    │
│  └─────────────┘  └─────────────┘    │
│                                       │
│  可随时切换，不影响数据               │
└──────────────────────────────────────┘
```

**Step 2A（投顾模式专属）：风险承受能力 + 现金流**
- 风险承受能力分级：保守 / 稳健 / 进取（三选一，影响告警阈值和语言）
- 月收入（可选）：用于把亏损换算成"相当于你月收入的 X%"
- 这两项是投顾模式的核心，决定后续风险告警的呈现方式

**Step 2B：示例持仓已加载**
- 自动加载示例持仓（贵州茅台 20% / 宁德时代 30% / 招商银行 30%）
- 顶部提示："这是示例数据。替换成你自己的持仓，开始真实体验。"
- 用户添加第一只真实持仓后自动清除示例数据

**Step 3：LLM 配置（如未配置）**
- 引导填写 API Key，或选择 Mock 模式先体验

**跳过**：每步可跳过。投顾模式跳过 Step 2A 时用默认"稳健"分级，不录入月收入（风险告警不换算成月收入比例）。

### 4.6 两种模式的差异化呈现

**个人投顾模式（默认）**——大白话 + 现金流换算 + 风险承受能力
```
┌─────────────────────────────────────────┐
│ 今日该关注（你的风险等级：稳健）          │
│                                         │

│   这次下跌让你浮亏 ¥2,300                │

│   （量能在缩，不像恐慌性抛售）            │
│   [看 K 线]                             │
│                                         │
│ 📰 央行降准了                            │
│   你持有招行（占你仓位 30%）             │
│   建议关注银行板块资金流向               │
│                                         │
│ 你的组合整体：🟢 健康                    │
│ 以上内容由 AI 生成，仅供参考，不构成投资建议│
└─────────────────────────────────────────┘
```

**专业投研模式**——术语直出 + 纯分析，不结合个人财务
```
┌─────────────────────────────────────────┐
│ 茅台 600519  1680 -1.2%                 │
│ PE 35.2 | ROE 32.1% | VaR 4.32%         │
│                                         │
│ [四维分析] [多空辩论] [财报] [技术面]    │
│                                         │
│ 多空辩论：偏多 3 / 偏空 2 / 中性 1       │
│ 共识：估值偏高但护城河深                 │
│                                         │
│ 以上内容由 AI 生成，仅供参考，不构成投资建议│
└─────────────────────────────────────────┘
```

**核心差异对比**：
- 投顾：跌 8.2% → "让你浮亏 ¥2,300，相当于月收入 15%"（结合现金流）
- 投研：跌 8.2% → "VaR 4.32%"（纯指标，不结合个人）
- 投顾：大白话"快到止损线了"
- 投研：术语"逼近支撑位"

## 七、详细设计

### 7.1 Daily Action Center（P4-0）★

**定位**：投顾模式首页。变化记录器，不是仪表盘。回答"与你持仓有关的事情发生了什么变化"。每条 = 信号 + 依据 + 行动按钮。最多 5 条（投顾模式）/ 20 条（投研模式）。负面信号必有平衡信息。

```
┌──────────────────────────────────────────────┐
│ StockResearch   [个人投顾] [专业投研]  中/EN  │
├──────────────────────────────────────────────┤
│                                               │
│  需要立刻关注                                  │
│  ⚠ 贵州茅台跌幅 8.2%，触及你设的止损关注线     │
│  但近 5 日量能缩窄，恐慌性抛售概率较低          │
│  [查看 K 线]                                  │
│                                               │
│  今日相关变化                                  │
│  📰 央行降准 0.5 基点                          │
│  → 因为你持有招商银行（仓位 30%，属银行板块）   │
│  [深度解析]                                   │
│                                               │
│  📊 白酒消费数据发布，贵州茅台关联              │
│  数据基本符合预期，未出现偏离                   │
│  [查看详情]                                   │
│                                               │
│  ────────────────────────────                 │
│  今日组合：🟢 健康  数据时间：15:23            │
│                                               │
│  [F1] [F2] [F6] [F4]                         │
└──────────────────────────────────────────────┘
```

**按交易时段差异化**：

| 时段 | 默认内容 |
|------|----------|
| 开盘前 8:00–9:30 | 昨日收盘后公告、重要新闻摘要 |
| 盘中 9:30–15:00 | 实时涨跌、异动提醒、触发阈值 |
| 收盘后 | 持仓日涨跌总结、风控状态更新 |

**空状态**：低于相关性阈值不推送，哪怕今天只有 1 条。显示原因："昨日收盘后持仓无明显变化，市场整体平稳。"

**信号来源**（规则优先，LLM 可选润色）：价格逼近支撑/阻力（距离 < 3%）、风控阈值触发、新闻关联持仓、基本面异动（ROE/营收变动 > 20%）。

### 7.2 F6 个股看板（P4-2）

**定位**：技术面 + 基本面 + 财报 + AI 分析，统一界面。投顾模式默认显示 AI 两句话 + 关键位置；投研模式默认显示四维完整 + 辩论。

**保留**：PE、ROE、营收增速、负债率、毛利率、净利率、财报对比表。

**砍掉**：斐波那契、VWAP、布林带。

│ ━━━━━━━━━━━━━━━━━━ 1650    │  · PE 高于行业均值 42%                   │

**辅助线**：支撑/阻力（标注触及次数，近期形成 < 历史验证），MA20（白）+ MA5（橙可选）。

**AI 两句话硬性写法**（投顾模式默认，投研模式可展开为完整四维）：

```
❌ "根据技术分析，该股处于下行通道，MACD死叉，RSI 42.1，建议关注。"

```

两句话 = 当前处境 + 市场状态。不写判断，只写观察。固化到 System Prompt。

### 7.3 风控人话解释（P4-3）

先交结论，再给数据。

```
┌──────────────────────────────────────────────┐
│ 组合风险：🟢 低                                │
│                                               │
│ 未来一天，95% 概率亏损不超过 ¥2,300            │
│                                               │
│ ▶ 查看详细指标                                 │
│   VaR · CVaR · Sharpe · Sortino · 最大回撤     │
└──────────────────────────────────────────────┘
```

**投顾模式**：默认显示人话结论，详细指标折叠。  
**投研模式**：默认展开全部指标。

**阈值归用户所有**（驾驶舱和投资顾问的根本区别）：

```
止损关注线：跌幅超过 [ 8 ]% 提醒我
仓位上限：单一板块超过 [40]% 提醒我
回撤告警：组合回撤超过 [15]% 提醒我
```

系统只监测推送，判断权在用户。

### 7.4 示例持仓模式（P4-4）

新人引导假设用户愿意先录入数据。真实心理是**先看到价值，才愿意投入**。

**方案**：首次访问自动加载示例持仓（贵州茅台 20% / 宁德时代 30% / 招商银行 30%），Daily Briefing、风控页、F6 看板全部正常运转。顶部显示："这是示例数据。替换成你自己的持仓，开始真实体验。[现在加持仓]"。

用户添加第一只真实持仓后自动清除示例数据。

### 7.5 金融术语百科（P4-5）

双保险：静态词库匹配（主路径）+ LLM 标记指令（辅助）。不依赖模型遵守格式。

点击 PE → 弹出：

```
市盈率（PE）
Price-to-Earnings Ratio
股价 ÷ 每股收益，衡量估值水平。

当前股票：35.2
行业均值：28.1

以上数据仅供分析参考。
```

"定义 + 当前上下文"的价值远高于纯百科。

**投顾模式**：默认开启术语弹窗。  
**投研模式**：默认关闭（术语直出），可在 Settings 开启。

### 7.6 持仓健康度（P4-6）

三维评分（分散度/质量/波动），绿黄红卡片，F4 顶部展示。

## 八、合规

1. 输出结尾展示：**「以上内容由 AI 生成，仅供参考，不构成投资建议。」**
2. 禁止输出买入/卖出/目标价/建仓比例等指令。
3. API Key 仅浏览器存储，日志不打印完整 Key。
4. **双模式合规边界**（V7.0 新增）：
   - 投顾模式的"建议关注"≠"建议买入"。只说"建议关注银行板块资金流向"，不说"建议买入招行"。
   - 投研模式的深度分析≠投资建议。四维评分、多空辩论都是分析工具，不是买卖信号。
   - 两个模式共享同一套合规规则，模式切换不改变合规边界。
