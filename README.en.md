# StockResearch — English

The repository homepage README is presented in **Chinese** (the product itself is bilingual zh/en in-app).

→ **[Open README.md](README.md)** · [PRD (zh)](docs/PRD.md)

Two north-star metrics drive every product decision (see README §"两个北极星"):

1. **Prediction accuracy** — AI analysis should predict the market as accurately as possible, via a *verifiable loop*: every prediction is recorded, scored at horizon, calibrated, and attribution-learned. Accuracy is measurable, displayable, improvable.
2. **Financial education** — help non-professionals understand financial markets, via *scenario-based teaching*: knowledge appears in-context (zero clicks) while you look at valuation percentiles, momentum, or risk exposure, tied to your own holdings.

Locally-run, free-data, BYOK. No broker connection, no trading, no fabricated data.
