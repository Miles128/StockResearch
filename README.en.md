# StockResearch — English

The repository homepage README is **bilingual** (Chinese + English).

StockResearch is a local, network-connected AI-native investment research MVP. It is not intended to become a hosted SaaS or a trading terminal. The product demonstrates how AI can connect holdings, market data, news, risk, and multi-agent research for both beginners and finance professionals.

The application uses one canvas with a stable top view bar: Holdings, Risk, Market, News & Reports, and AI Chat. User facts are shared globally, conversations remain scoped to a task thread, and canvas context is attached explicitly and can always be removed. Market conclusions expose source, fetch time, cache/mock status, degradation, and optional enhanced data configuration.
